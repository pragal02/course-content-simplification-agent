# Course Content Simplification Agent

## Project Overview

The Course Content Simplification Agent is an AI-based educational assistant developed as part of an AICTE/IBM project. It uses IBM watsonx.ai and IBM Granite to simplify academic course content according to the learner's proficiency level.

## Objective

To help students understand complex academic concepts by generating explanations appropriate for their proficiency level.

## Learner Levels

- Beginner
- Intermediate
- Advanced

## Input

The user provides:
1. Academic/course content
2. Learner proficiency level

## Output

The system generates:
- Simplified explanation
- Key concepts
- Important terms and definitions
- Examples or analogies where useful
- Short summary
- Quick questions for self-assessment

## Technology Used

- IBM watsonx.ai
- IBM Granite Foundation Model
- Prompt Engineering
- Generative AI

## Workflow

Academic Course Content + Learner Level
→ IBM Granite Model
→ Level-appropriate Processing
→ Simplified Explanation
→ Key Concepts + Examples + Summary + Questions

## Sample Use Case

Input:

**Topic:** Computer Networks  
**Level:** Beginner

The system converts technical networking concepts into simple explanations with examples and key terms suitable for a beginner.

## Advantages

- Personalized learning
- Simplifies complex academic concepts
- Supports multiple proficiency levels
- Reduces learning difficulty
- Provides structured explanations
- Can be used across different academic subjects

## Future Scope

- Multilingual explanations
- Automatic difficulty-level detection
- Interactive quizzes
- Voice-based learning
- Integration with Learning Management Systems
- Personalized learning recommendations

## IBM watsonx.ai Implementation

The project is implemented using IBM watsonx.ai with an IBM Granite foundation model. Prompt engineering is used to control the explanation level and generate structured educational content.

## Project Status

Working prototype completed and tested using IBM watsonx.ai.
